# 🎮 2048 Game

This project is a web-based clone of the classic puzzle game **2048**. It is designed to provide smooth gameplay, score tracking, and dynamic tile animations, all built entirely from scratch without the use of heavy frameworks.

The primary focus of this project was to implement complex game logic, manage state, and handle DOM manipulations efficiently using pure JavaScript.

## 🌐 Live Preview

Explore the game and try to reach the 2048 tile live on GitHub Pages:
**[Play the Game](https://romanplyta.github.io/js_2048_game_v1/)**

## 🚀 Technology Stack

* **Logic & Interactivity:** `Vanilla JavaScript (ES6+)` – Core game mechanics, matrix calculations, tile merging logic, and keyboard/touch event handling.
* **Structure:** `HTML5` – Clean markup for the game board, scoreboards, and UI elements.
* **Styling:** `SASS / SCSS` – Utilized for writing modular CSS, managing colors for different tile values, and handling smooth CSS transitions.
* **Responsiveness:** `CSS3 Media Queries` – The game board adapts perfectly to both desktop and mobile screens.

## ✨ Key Features

* **Classic Mechanics:** Authentic 2048 rules with smooth sliding and merging animations.
* **Score Tracking:** Real-time updates for the current score.
* **Responsive Layout:** Playable and visually appealing on all device sizes.
* **Zero Dependencies:** Built purely on native web technologies for maximum performance.

## ⚙️ Installation and Setup

To run this project locally, follow these steps:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/romanplyta/js_2048_game_v1.git](https://github.com/romanplyta/js_2048_game_v1.git)
    ```

2.  **Navigate to the Project Directory:**
    ```bash
    cd js_2048_game_v1
    ```

3.  **Install Dependencies:** *(If you are using a bundler or SCSS compiler like in the previous project)*
    ```bash
    npm i
    ```

4.  **Launch the Project:**
    ```bash
    npm start
    ```
    *(This command will start a local development server and open the project in your default browser. If you don't use npm for this project, simply open `index.html` in your browser).*
